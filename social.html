How to build infographics people save

Structured, information-dense visuals that turn expertise into frameworks people can understand, save, and reuse.

The headline rule

Every infographic starts with “How to” and highlights one meaningful keyword in the red gradient capsule.

01 / Canonical shell

Start from the same template every time.

Headline: begins with the exact words “How to”.
Highlight: one meaningful keyword in DM Serif Display Italic inside the red gradient capsule.
Shell: fixed 1080 × 1350 canvas, edge guides, faint document texture, author, and wordmark.

02 / Design character

Dense enough to teach. Clear enough to scan.

01

Structured

Tables, panels, steps, tiers, diagrams, labels, and comparisons create visible logic.

02

Substantial

Copy earns its space. The visual can hold a complete framework, not only a slogan.

03

Editorial

Flat fields, crisp navy outlines, strong typography, and blue information coding make it feel published, not productized.

03 / Palette

Red stops the scroll. Blue organizes the information.

The palette is deliberately narrow: pale blue paper, dark navy structure, a blue information scale, and one red headline moment.

04 / Panel language

Composition follows the argument.

How to build a founder-content engine

01 Make the problem visible
  • Name the costly status quo
  • Show the practical consequence
  • Use a concrete example
02 Introduce a better way
  • Explain the model
  • Map each part to an outcome
  • Keep labels specific
03 Prove it works
  • Add screenshots or evidence
  • Use numbers where available
  • Separate signal from opinion
04 Make it reusable
  • End with a process
  • Give the reader a next action
  • Design for saves and shares

05 / Core archetypes

Five layouts cover most educational ideas.

FRAMEWORK

Framework grid

Parallel modules that explain distinct parts of one system.

COMPARE

Comparison matrix

Columns and rows that make differences obvious at a glance.

BREAKDOWN

Annotated source

A real post, workflow, or screenshot paired with a structured explanation.

PROGRESSION

Tiered ladder

Levels of maturity, complexity, trust, or value connected in sequence.

SYSTEM

System map

Flows, loops, funnels, ladders, and diagrams that show how a mechanism behaves.
