# Enablement website and document design

The [Enablement website](https://www.enablement.ch/) uses a single dark theme. Follow the [website design and page plan](site-plan.md) when designing a page. The [production stylesheet](https://github.com/enablement-ch/enablement-site/blob/main/src/styles/global.css) defines the colors, fonts, spacing and other tokens. The [Astro components](https://github.com/enablement-ch/enablement-site/tree/main/src/components) define how they are applied.

Use the [HTML preview](index.html) to inspect examples. When the site changes, update the guide and preview from the implementation in `enablement-site`.

For PDFs, reports and workbooks, use the [document design system](enablement-design.md). For LinkedIn graphics, use the social design system in `~/Claude Code/enablement-brain/Social Content Guidelines/DESIGN_SOCIAL.md`.
