# Canonical Editorial Infographic References

These six images define body composition and information treatment for
Enablement's LinkedIn visuals. The system is editorial, information-dense,
modular, and flat. It does not use SaaS glassmorphism.

They do not override the canonical shell in
`../../templates/linkedin-infographic-template.svg`. New Enablement
infographics must use that template's red-and-blue palette, footer, and headline
grammar: begin with `How to` and highlight one meaningful keyword.

The reference images include external inspiration and Enablement-produced work.
Use them to learn composition and information treatment. Do not copy another
creator's branding, wording, or proprietary framework.

## Reference 01 - Top 1% Communicator

**File:** `01_top-1-percent-communicator.png`

What it teaches:

- A large headline can coexist with a genuinely dense comparison matrix.
- Repeated rows make three pillars easy to compare horizontally.
- Pastel column headers organize categories without decorative complexity.
- Small diagrams and bullet blocks can share the same cell system.
- Strong rules and restrained shadows are enough to create hierarchy.

Use for: three-part frameworks, capability comparisons, and multi-row matrices.

## Reference 02 - Content Accessibility Ladder

**File:** `02_content-accessibility-ladder.png`

What it teaches:

- A vertical progression can communicate audience maturity immediately.
- Real example thumbnails make abstract tiers concrete.
- Flat color bands establish level changes without cards or depth effects.
- Short attribute pills support the main narrative without becoming decoration.

Use for: beginner-to-advanced systems, maturity models, and trust ladders.

## Reference 03 - Viral Infographics Comparison

**File:** `03_viral-infographics-comparison.png`

What it teaches:

- A simple three-column matrix can carry substantial copy when field order is
  repeated consistently.
- Tinted headers and matching pills create category identity.
- Mini-bars turn qualitative differences into an instantly readable visual.
- The visual is minimal in surface treatment, not in information volume.

Use for: role comparisons, product tiers, service models, and approach matrices.

## Reference 04 - Founder Content Engine

**File:** `04_founder-content-engine.png`

This is an Enablement reference and the strongest current brand translation.

What it teaches:

- One decisive red headline capsule creates the brand moment.
- Four large panels can mix a ladder, Venn diagram, source map, and pipeline.
- Navy outlines and tinted section bands hold different diagram types together.
- A clean white canvas supports density without looking like a dashboard.
- Author and wordmark attribution can remain outside the information grid.

Use for: four-part systems, end-to-end methodologies, and operating models.

## Reference 05 - Inbound Leads Post System

**File:** `05_inbound-leads-post-system.png`

This is an Enablement reference and the canonical annotated-breakdown pattern.

What it teaches:

- A real LinkedIn post can function as the evidence column.
- Color annotations connect source material to a six-step explanation.
- Substantial copy stays readable when divided into numbered editorial panels.
- A highlighted headline phrase provides the only strong brand accent.
- The reader sees the example and the method simultaneously.

Use for: post teardowns, case-study breakdowns, and annotated examples.

## Reference 06 - Four-Pillar Content Framework

**File:** `06_four-pillar-content-framework.png`

What it teaches:

- A two-by-two grid remains readable when every quadrant uses a different
  diagram type.
- Soft category tints can carry the color system while the canvas stays plain.
- Supporting copy can be concise because the diagram performs the explanation.
- Flat shapes and thin outlines feel editorial rather than product-led.

Use for: pillar frameworks, category maps, and balanced four-part systems.

## Synthesis

Across all six references:

- Information architecture creates the visual impact.
- Flat panels, table rules, and blue-family information coding replace glass and
  ambient depth.
- Copy is allowed when it is structured.
- Diagrams and real examples make the framework specific.
- Large headlines stop the scroll; dense bodies earn the save.
- The canvas is visually restrained and informationally rich.

## Canonical shell

Use `../../templates/linkedin-infographic-template.svg` for:

- 1080 x 1350 canvas and 20px edge guides;
- faint document-grid texture;
- fixed bottom-left author and bottom-right Enablement attribution;
- `How to` headline start;
- one highlighted keyword in the `#FF3762` to `#E11E48` capsule;
- DM Serif Display Italic for that highlighted keyword, with Sofia Sans for all
  remaining functional text;
- `#17365F` structural outlines and the approved blue information family.
